# Ashfall Road — creature portrait prompts (ChatGPT / Gemini)

Ten creatures still need portraits. Each prompt below is short on purpose: free image models follow a short brief plus a reference image far better than a long one.

## Before you start

1. Open **one** chat in ChatGPT (or Gemini) and keep it for all ten creatures.
2. Attach **`art_sources/style_reference/BEST_REFERENCE.png`** (the full-size Feral Dogs source). For creatures with odd, hairless anatomy (Bile Spewer, Reservoir Maw, Cable Eater), also attach `SECOND_REFERENCE_creature_anatomy.png` (the Ash Stalker source).
3. Paste the **style lock** (below) as the first message, together with the first creature.
4. For every following creature, start the message with **"Same style as the reference image, new portrait:"** and paste only the creature block.
5. If an image drifts into another style, reply only: *"Wrong style. Redraw this exact image in the style of the reference image."*
6. Save each image you like as `art_sources/portraits/<file name>_source.png`, using the file names in the table, and tell Claude. Claude converts it to 128×128 and adds it to the game.

## Style lock — paste first, once

```text
Match the EXACT art style of the attached reference image: same chunky pixel art, same painterly shading in stepped colour blocks, same muted dark palette, same flat dark #20272B background, same tight close crop where the creature fills most of the square and is cut off by the frame edges. It must look like the same artist made it for the same grim post-apocalyptic game. Do not make it smooth, realistic, anime, cartoon or 3D. Scary and adult in tone: dirt, scars, dried blood and disturbing anatomy are fine, but no gore, no exposed organs, no open wounds, no corpses or victims. Square image, no text, no border, no scenery, no glow effects.
```

## 1 · Shutter Skitters

```text
ENEMY "Shutter Skitters": a colony of flat, plated creatures the size of a spread hand, crawling out of a dark gap. Their overlapping plates look exactly like broken grey roof slates, so at first the image reads as a pile of slate that is moving. One large skitter close in the foreground, pressed flat, plates slightly lifted, thin jointed legs gripping; a dozen more behind it at different angles, some half-hidden. No eyes visible, only a small dark mouth slit under the front plate. Grey slate, charcoal and dusty brown palette with one cold highlight. Feeling: the tapping in the wall was them all along.
```

## Quick fixes

- **Too clean or cute:** *"Make it more disturbing and grim: dirtier, more scarred, darker palette, keep the same pose."*
- **Too gory:** *"Remove any open wounds or exposed flesh. Keep only dried, dark, matte stains."*
- **Background not flat:** *"Make the background one flat dark #20272B colour with no scenery, fog or glow."*
- **Too small in frame:** *"Crop much closer so the creature fills the square and is cut off by the edges."*
- **Wrong style:** *"Wrong style. Redraw this exact image in the style of the reference image."*
