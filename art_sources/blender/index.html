ASHFALL ROAD / ASSET WORKSHOP

Archived Blender experiment.

Editable, posed 3D sculptures based on the enemy briefs. Large images show the Blender renders; the small images are archived experimental portraits. The user rejected this look, and the previous game assets have been restored. All sprites use a shared 20-color palette.

This is a faceted first pass for portrait use. The models have no animation rigs; detailed facial sculpting and final art approval remain separate.
