# Portrait production sources

This directory stores the high-resolution source selected for each portrait. Godot ignores the directory through `art_sources/.gdignore`; only approved 64×64 PNG files belong under `assets/portraits/`.

Use `<portrait_id>_source.png` for the selected source and record its prompt, generator, edit history, and approval state in `docs/GEMINI_PIXEL_ART_PROMPTS.md` and `docs/ASSET_PROVENANCE.md`.
